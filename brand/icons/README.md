# Icons

Lucide (https://lucide.dev), version 0.453.0, ISC licence. Exported at the brand stroke width of 1.5px.
Stroke is `currentColor`: the icon takes the text colour it sits in.

- More icons: search https://lucide.dev/icons, set stroke width to 1.5 in the side panel, then Download SVG (or Copy SVG).
- Affinity: File > Place the SVG, then set the stroke colour from the palette. Keep stroke 1.5px at 24px size (scale strokes with the object).
- Cut-in (etched) style is applied in CSS or by hand: ink at black 32% with a faint lower light edge. See brand-guide.md section 2.
